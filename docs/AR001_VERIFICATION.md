# AR001 有界自动返修：开发与隔离验证报告

状态：领域层、Runtime、HTTP 和最小界面已实现，主会话独立测试及隔离浏览器闭环通过。变更保留在 feat/bounded-auto-repair 工作树，未提交、未推送、未创建 PR、未部署或合并。正式工作台数据库与任务策略未改变。

## 实现结果

- 每任务显式开启，默认关闭，绑定当前批准任务稿。
- 首次开发不计自动返修额度，最多两次自动返修；第三次不启动。账本跨重启和关闭保留。
- Issue/任务稿版本往返及 defer 后重新 develop 不恢复旧 opt-in。
- 只消费当前 Run/head 的有效 changes_requested，沿用固定模板、范围与 RF001 冻结反馈。
- 实时核验 Issue/PR，逐次领取前重新核验本地占用。未知整理、合并意图、损坏控制文件阻塞自动领取。
- 任务详情与验收页展示启停按钮、已用额度、剩余额度和阻塞原因。关闭不撤销正在运行的 Worker，不退回额度。
- 不自动生成评审、不自动批准、不自动合并。
