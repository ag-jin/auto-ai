# AR001 开发复盘与后续检查清单

状态：首次复盘，后端修复尚待最终独立复核，UI 尚未实现。本文不代表功能验收通过，也不授权部署、推送或合并。

## 已发生的问题与证据

- Runtime/HTTP 第一轮先实现、后在隔离旧代码上补红灯。这证明测试可发现缺失实现，但不符合先红后绿。必须如实记录，不能用补跑改写开发顺序。
- 既有全量 150/150 通过后，独立测试仍复现领取竞态：等待 PR 读取期间通过公开接口启动整理，自动返修随后仍启动。证据：中央 `evidence-runtime/independent-race-red.log`。
- Worker 回归进一步复现整理 unknown、损坏 merge-intent 和 control 被放行。文件损坏属于故障注入路径，不能与正常公开操作可达竞态混为一谈。证据：`evidence-runtime-repair/red-*.log`。
- 叫 green 的日志曾有失败，较早的全量日志也不包含后来新增测试。文件名、存在性和旧测试计数都不是通过证明。
- 等待程序超时不代表 Pi Worker 失败。曾出现 observer 退出但实际 Worker 仍运行；必须核对真实状态，不能重复派发。
- 审查代理隔离目录与目标目录不一致，Git 差异访问受限。只读源文件审查可继续，但其结论不能冒充完整差异审查，也不能让主会话代为绕过拒绝。

中央证据目录：主仓库 `.auto-ai/validation/auto-repair/`。保留原始失败日志，不覆盖为成功日志。当前修复结果仍需主会话独立验证。

## 后续小步开发的强制验收清单

### 写实现前

1. 固定需求、允许改动文件、现有 Worker 终态及本轮修复次数。
2. 写最小公开行为回归，实际运行确认它因目标行为失败。保存命令、时间、退出码和原始日志。
3. 如果测试失败只是环境、夹具或断言本身出错，先修测试，不能当作缺陷红灯。
4. 新增缺陷使用独立命名的红灯证据。禁止实现后回滚副本再声称先红后绿。

### 自动化安全边界

- 默认关闭；启用绑定当前批准版本；撤销不可因内容恢复而复活；切换和重启不清空消费账本。
- 每个异步等待都可能让授权、进程占用、评审或意图变化。远程验证前的本地检查不能代替最终领取检查。
- 每次同步领取之前重新检查 Runtime 本地安全条件，并与领域层授权/预算/评审检查共同生效。包括核验其他候选及准备前一个 Run 后的窗口。
- 明确区分“标记不存在”“标记读取/解析失败”“进程已确认停止”“进程未知”。未知和读取失败保守阻塞受影响自动任务，不阻塞无关手动任务。
- 安全关键读取不要复用为展示便利而吞错返回 null 的接口，除非能保留缺失与故障的区别。
- 不通过自然语言分类替代授权；不伪造评审；不自动合并。

### 必须补齐的测试维度

- 正常首次开发、两次自动返修、第三次拒绝，自动路径 merge 调用为零。
- 同一事件重复、重启、关闭再开启、版本往返、defer 后重新 develop。
- 容量等待期间来源/head 漂移、关闭、合并意图、未知进程。
- 用可控 Promise 屏障而非 sleep，覆盖远程读取期间及跨候选/跨领取异步窗口中的并发变化。
- 适配器异常、损坏或不可读安全标记。每项既断言受影响任务不启动，也断言无关任务继续。
- 保持原始反馈、模板、任务版本与写入范围，验收与合并仍为显式操作。

### 交付与独立复核

1. 确认 Worker 已终止后再独立跑测试，避免验证过程中代码继续变化。
2. 读取每个命令真实退出码和测试汇总；不得只凭后台组合命令总退出码或日志名判定成功。
3. 最后一次代码/测试改动后重跑专项、全量、工作流和 Runtime 检查。交付报告绑定最终文件版本或内容摘要。
4. 独立审查不仅读绿灯日志，还检查未覆盖的状态转换与异步边界。发现具体缺陷先加失败回归，再派修复 Worker。
5. 区分自动返修测试中的零合并与既有显式人工合并夹具中的模拟调用；禁止混写成全套测试零合并。
6. 报告区分 Worker 声称、主会话独立验证、静态疑点、已执行复现及未覆盖内容。
7. 同一缺陷最多两轮自动修复，仍失败就保留证据并报告阻塞。

## 调度改进

- 以代码、测试或证据产物变化判断实质进展，不把频繁读文件当作产出。
- 完成通知为主要等待手段。定时核对只报告新增进展、失败或决策需求，减少无变化播报。
- 观察程序超时先核对实际 Pi 进程；状态未知时保留现场，不新建重复执行。
- 审查派发前核对目标 checkout 与隔离方式；缺少 diff 的审查必须注明范围。
- 复盘清单必须写入下一阶段 Worker 简报，不能只存档。新发生的同类缺陷优先变成确定性测试，通用检查有稳定需求后再实现脚本，不擅自扩大功能范围。
